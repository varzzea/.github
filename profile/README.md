# Varzzea

**Gestão esportiva para arenas, campeonatos e aulas.**

[Site](https://varzzea.com.br) · [App](https://app.varzzea.com.br) · [Instagram](https://www.instagram.com/navarzzea) · [Contato](mailto:navarzzea@gmail.com)

</div>

---

A Varzzea reúne a operação de arenas esportivas e a experiência dos atletas em uma única plataforma. Nasceu no beach tennis amador e foi desenhada para a realidade do esporte no Brasil.

| Módulo | Descrição |
| --- | --- |
| **Arenas** | Cadastro e gestão de arenas |
| **Campeonatos** | Inscrições, chaves, jogos e resultados |
| **Aulas** | Turmas, alunos e professores |
| **Pagamentos** | Pix com repasse direto para a arena ou o professor |

Disponível na web, iOS e Android.

Quer levar a Varzzea para a sua arena? Escreva para **navarzzea@gmail.com**.
